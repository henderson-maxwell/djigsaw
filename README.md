# Introduction

Thhis project is a collection of Web Templates and UI Components that make use of the stack:
    - Django
    - HTMX
    - AlpineJS

It is meant to provide composible blocks and components using django-template-tags to quickly design and deploy webapps and websites.

Websites have less design cohesion than webapps though.

## To start dev server:

```bash
cd src && python manage.py tailwind dev
```
